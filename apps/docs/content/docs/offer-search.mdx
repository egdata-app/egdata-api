---
title: Find games
description: Search the catalog, combine filters, and order results.
---

Use `POST /search/v2/search` to find store offers by title and filter them by offer type, tags, seller, developer, publisher, category, detected technology, or regional price. Send the visitor's two-letter country code as `country` so price filters and returned prices use the right region.

```js
const response = await fetch(
  "https://api.egdata.app/search/v2/search?country=US&locale=en-US",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      title: "co-op adventure",
      offerType: "BASE_GAME",
      onSale: true,
      sortBy: "discountPercent",
      sortDir: "desc",
      page: 1,
      limit: 20,
    }),
  },
);
const result = await response.json();
```

The response contains a total count, matching offers, the requested page and limit, and filter aggregations. Each offer includes a `price` for the selected region, or `null` when no regional price is available.

```json
{
  "total": 1,
  "offers": [{ "id": "offer-id", "title": "Example Game", "price": null }],
  "page": 1,
  "limit": 20
}
```

`title` searches titles and related text with fuzzy and synonym matching. Filters can be combined. `tags` requires all supplied tag IDs; `technologies` requires every named detected technology. The response always includes technology buckets under `aggregations.technologies.buckets`.

`page` starts at 1. `limit` defaults to 10 and is capped at 100. Without `sortBy`, text searches rank by relevance and other searches sort by most recently modified. Common `sortBy` values include `releaseDate`, `lastModifiedDate`, `price`, `discount`, `discountPercent`, `priceUpdatedAt`, `upcoming`, and `giveawayDate`; `sortDir` is `asc` or `desc` and defaults to `desc`. Set `sortBy: "price"` and `sortDir: "asc"` for the lowest price first. Price sorting uses the selected country's region. Some release date sorts also restrict results to future or released offers.

For meaning-based queries, see [natural-language search](/docs/natural-language-search).

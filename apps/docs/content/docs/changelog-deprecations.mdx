---
title: Track changes
description: Retrieve catalog updates to keep your app's data current.
---

Use `GET /changelist` to retrieve recent catalog changes without fetching every game again.

```js
const response = await fetch(
  "https://api.egdata.app/changelist?page=1&limit=10",
);
if (!response.ok) throw new Error(`Request failed: ${response.status}`);
const changes = await response.json();
console.log(changes);
```

Use `GET /changelist/{id}` for a specific record, or `GET /search/changelog` to search changes.

## Read changes

Search results include `metadata.changes[]` entries with `oldValue` and `newValue` when available. Raw value fields may also be present. An abbreviated change entry with illustrative values:

```json
{ "oldValue": "Old title", "newValue": "New title" }
```

Recent and individual changelist records include best-effort `metadata.context`. It can be `null` when related data is unavailable.

Ignore unknown response fields, handle nullable values, and use stable IDs to refresh affected records. Avoid depending on undocumented ordering.

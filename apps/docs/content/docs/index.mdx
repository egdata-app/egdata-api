Use egdata to build game discovery tools, price trackers, and free-game apps.

## Base URL

```txt
https://api.egdata.app
```

## Make your first request

Fetch five recently updated offers:

```js
const response = await fetch(
  "https://api.egdata.app/offers?country=US&locale=en-US&page=1&limit=5",
);
if (!response.ok) throw new Error(`Request failed: ${response.status}`);
const data = await response.json();
console.log(data.elements.map((offer) => offer.title));
```

Abbreviated response with illustrative values:

```json
{
  "elements": [{ "id": "example-offer-id", "title": "Example Game" }],
  "page": 1,
  "limit": 5,
  "total": 100
}
```
